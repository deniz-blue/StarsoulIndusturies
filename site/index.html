Any launcher that lets you set JVM arguments works, the official Minecraft Launcher too.

  1. Make an instance

    Minecraft {{minecraft}} with NeoForge {{neoforge}}.

    In the Minecraft Launcher: run the NeoForge installer and click Install client. Then open Installations → New installation, pick neoforge-{{neoforge}} and an empty folder as the game directory.

  2. Add unsup

    Download unsup.jar and unsup.ini into the instance's game folder, the one that has options.txt. In the Minecraft Launcher, that's the game directory you picked.

    Add -javaagent:unsup.jar to the instance's JVM arguments. The Minecraft Launcher has them under More options.

  3. Play

    The modpack will be automatically updated every time you launch the game. The IP address is already pre-filled for you, but here it is just in case: starsoul.industries

    When the NeoForge version changes, change it in the launcher too.
